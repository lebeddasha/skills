# Уроки ошибок из истории

Источники: сообщения пользователя и требования заданий из [sources.md](sources.md). Старый ответ ассистента — материал для проверки, не эталон.

| Ошибка | Правило следующей работы |
| --- | --- |
| Перебор комбинаций ответа теста с уверенным тоном | Нужен текст урока/обратная связь курса. Последняя комбинация «Кто + Зачем + Что + Как + Чем» не подтверждена; не хранить как верный ответ |
| Под видом одной модификации изменены сопротивление, повторы и отдых | Полное состояние до/после; сравнение соседних уровней; ровно один управляемый параметр |
| Регрессия возвращает сразу несколько условий базы | Упростить только выбранное условие; при нескольких необходимых изменениях честно назвать новое решение, не чистый тест |
| В «когда усложнить» написано «добавить вес» | Назвать наблюдаемый критерий и отдельно способ изменения |
| Столбцы прогрессии, регрессии и стоп-сигналов смещены | Сопоставить заголовок с каждым ответом, проверить соседние строки после правок |
| В плане есть «ступень», но упражнения на нее нет | Проверить соответствие цели содержанию |
| Вторая силовая полностью дублирует первую вопреки запросу | Изменить состав осмысленно, сохранить необходимые паттерны и дозу |
| В списке выбран несуществующий тип нагрузки | Читать фактический источник валидации, не изобретать категории |
| Осталась пустая «граница вывода» | Проверять все обязательные поля и части задания, а не только основные упражнения |
| Обновлен текст, но не сам Excel | Если запрошена правка файла, сохранить новую копию и проверить связанные листы |
| Сценарий выдан за фактический разбор | До съемки — план; после — только доступные наблюдения. Пропущенный вопрос не дописывать как заданный |
| Всем пунктам аудита поставлено «да» | Для каждого пункта требуется реальная проверка; неизвестное отмечать честно |
| Разминка стала работой до отказа или набором без логики | Указать функцию каждого этапа RAMP и связь с основной частью |
| Потеря техники названа полезной нагрузкой на мозг | Сравнить с базой, упростить/убрать задачу при ухудшении |
| Большая амплитуда автоматически объявлена прогрессом Алины | Объяснить связь с ее целью и сохранение контроля |
| Возраст, осанка или единичная реакция стали диагнозом/запретом | Сохранить границу вывода, учитывать функцию и контекст |
| Время блока названо без сложения подходов и отдыха | Считать работу, стороны, фактическое число пауз, переходы и объяснение отдельно |

Последние две недели/четыре недели в задании могут быть воображаемым сценарием. Это не повод переписать исходные показатели профиля как реально улучшившиеся.

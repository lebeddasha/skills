# Профили учебных клиентов

Прочитай только профиль нужного клиента и актуальное задание:

- [Никита](clients/nikita.md) — гипертрофия, сила, контроль скорости.
- [Алина](clients/alina.md) — сила, контроль, уверенность, коммуникация.
- [Сергей](clients/sergey.md) — переносимость нагрузки, выносливость, снижение массы.
- [Ирина](clients/irina.md) — функциональные цели, сила, баланс, учет лекарств.

Это данные учебных кейсов из сообщений пользователя, а не медицинские карты реальных людей. Сценарии «представьте, что через две недели…» сохраняй как условия конкретного задания, не как доказанные результаты программы. Исходные возраст и измерения не обновляй автоматически с календарем.

Новые сведения добавляй с датой, названием задания, источником и статусом. Пример записи: «В задании X сообщено Y; меняет решение Z; проверить W». При противоречии приведи оба контекста и используй актуальный для задания. Обобщение прежнего ассистента не сильнее первичного текста пользователя.

# Установка и использование

Архив содержит папку `fit-sheets` с готовым локальным навыком. Он не требует аккаунта сервиса, API-ключа или MCP-сервера. Архив подготовлен для установки; распаковка в произвольную папку сама по себе не подключает навык к Codex.

## Установка

Если папка скачана вместе с репозиторием, на macOS или Linux запустите `./install.sh fit-sheets` из его корня. Для ручной установки следуйте шагам ниже.

1. Распакуйте `fit-sheets.zip`.
2. Скопируйте целиком папку `fit-sheets` в пользовательский каталог навыков:
   - macOS/Linux: `~/.agents/skills/fit-sheets`.
   - Windows: `%USERPROFILE%\.agents\skills\fit-sheets`.
   Альтернатива для одного проекта: `<папка проекта>/.agents/skills/fit-sheets`.
3. Проверьте, что файл расположен непосредственно как `fit-sheets/SKILL.md`, без двойной вложенности `fit-sheets/fit-sheets`.
4. Откройте новый чат Codex и вызовите `$fit-sheets`. Если навык не появился, перезапустите Codex. В интерфейсе с выбором через `@` выберите «fit-sheets».

Если папка с таким именем уже существует, сначала сохраните ее отдельную резервную копию и сравните профили. Не заменяйте накопленные сведения о клиентах молча и не устанавливайте одну версию одновременно в несколько мест.

Текущие пути и формат проверены 25.11.2026 по [официальной документации OpenAI](https://learn.chatgpt.com/docs/build-skills). В этой поставке установка на компьютер автоматически не выполнялась.

## Первый запрос

Прикрепите исходный Excel, текст задания и нужный конспект. Можно написать:

```text
$fit-sheets
Заполни приложенный Excel простыми словами по этому заданию.
Используй профили Никиты, Алины и Сергея. Для видео беру тягу эспандера дома.
Видео еще не снято, поэтому результаты не придумывай.
Сохрани оригинал, формулы, оформление и выпадающие списки.
Проверь соседние ступени на одно изменение и арифметику дозировок.
Верни отдельный заполненный файл и короткий отчет проверки.
```

После записи:

```text
$fit-sheets
Обнови только видео-протокол и самоанализ в приложенной копии.
На записи о лекарствах я не спросила. Партнер отказался обсуждать колено,
затем согласился сообщать о боли и возражал против маленькой нагрузки.
Сохрани фактические пропуски и добавь, что я сделаю иначе в следующий раз.
```

Для Ирины:

```text
$fit-sheets
Заполни задание по Ирине. Учитывай бета-блокатор, остеопению и цели из кейса.
Не заполняй будущие результаты как реальные. В видео механику показываю на себе.
Проверь, что работа со ступенью действительно есть, а время сессии сходится.
```

## Проверка

Для валидатора нужен Python 3.9 или новее. Дополнительные библиотеки не нужны. Инструкции и примеры — в `references/validation.md`. Обычно Codex сам готовит карту ячеек и запускает проверку. Валидатор только проверяет: заполнение книги выполняет Codex через доступный инструмент Excel.

Проверить комплект вручную из папки навыка:

```sh
python3 -m unittest discover -s tests -v
python3 scripts/validate_workbook.py --help
```

Для Windows вместо `python3` можно использовать `py -3`, если так установлен Python.

## Обновление профилей

Попросите Codex добавить новые сведения в соответствующий файл `references/clients/`, сохранив дату, источник и статус. Фраза «представьте, что через две недели…» должна остаться учебным сценарием. При обновлении всего навыка переносите свои дополнения отдельно.

Профили внутри навыка используются как учебные кейсы.

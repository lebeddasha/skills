# История изменений

## В разработке

- Исходная ссылка Excel сохраняется в отчете проверки. На Mac при наличии сохраняется и атрибут Finder «Откуда» для локальной копии.
- Добавлен voice.md по пяти заполненным таблицам с формами ответов для разных типов ячеек, словарем и примерами.
- Для нового текста запрещены твердый знак, типографские тире и точка с запятой. Числовые диапазоны записываются через обычный дефис.
- Для нового текста в `fit-sheets` закреплены замена букв U+0451 и U+0401 на «е» и «Е» и запрет длинного тире (U+2014).

## 0.1.0 — 2026-11-25

- Добавлен `fit-sheets` для заполнения и проверки домашних заданий по фитнесу в Excel.
- Добавлены учебные профили, рекомендации по заполнению и подготовке видео, валидатор Excel и его тесты.
- Добавлен `install.sh` для установки одного или нескольких навыков в Codex.
- Добавлены инструкции по установке и лицензия MIT.
